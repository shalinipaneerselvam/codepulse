Find Largest Number

Find the largest element from the given array.

Easy

Problem Statement

Given an array of integers, your task is to find the largest element present in the array.

Example:
Input: 10 25 7 42 18
Output: 42

Explanation:
Among all the elements, 42 is the largest number.

Try Your Input

Result:

Java Solution 

public class Main {

    public static void main(String[] args) {

        int[] numbers = {10, 25, 7, 42, 18};

        int largest = numbers[0];

        for (int i = 1; i < numbers.length; i++) {

            if (numbers[i] > largest) {
                largest = numbers[i];
            }

        }

        System.out.println(largest);
    }
}
