Prime Number

Check whether a given number is Prime or Not Prime.

Easy
Example

Input: 17
Output: Prime Number

Try Your Input


Result:

Java Solution


int num = 17;
boolean isPrime = true;

if (num <= 1) {
    isPrime = false;
}

for (int i = 2; i <= Math.sqrt(num); i++) {

    if (num % i == 0) {
        isPrime = false;
        break;
    }
}

System.out.println(isPrime);
