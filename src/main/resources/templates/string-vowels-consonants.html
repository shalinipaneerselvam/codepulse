Count Vowels & Consonants

Count the number of vowels and consonants.

Example: hello → Vowels: 2, Consonants: 3

Result:

Java Solution

int vowels = 0;
int consonants = 0;

for(char ch : text.toLowerCase().toCharArray()) {
    if(ch >= 'a' && ch <= 'z') {
        if(ch == 'a' || ch == 'e' || ch == 'i' ||
           ch == 'o' || ch == 'u') {
            vowels++;
        } else {
            consonants++;
        }
    }
}
